Pages

Models

A model behind one of the library's lazy loaders (langai.LazyEmbedder, LazyImageEmbedder, LazyCompleter) loads on the first call that needs it; its identity and dimensions come from its spec, so the stores are set up before anything loads. load now calls Load.

Collections

Every index a page keeps, with the model the store recorded its vectors under (vector.Store.Model). A collection that records another model than the page runs refuses writes and searches (vector.ErrModelMismatch) until reset empties it (Index.Reset, MediaIndex.Reset); the page's next scan builds it again.

Embedding cache

The Tagger keeps every embedding it makes in a tagging.EmbeddingCache, keyed by model and text. Tagger.Prune removes what was not used for a while, after marking what the notebook's tags are built from as used.
