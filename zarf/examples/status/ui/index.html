Each feature has a page of its own: open one to try it on the media and documents below.

A model behind one of the library's lazy loaders (sense.LazyEmbedder, LazyImageEmbedder, LazyCompleter) loads on the first call that needs it. Its identity and dimensions come from its spec, so the stores are set up before anything loads. load now calls Load.

Every index a feature keeps, with the model the store recorded its vectors under (vector.Store.Model). A collection that records another model than its page runs refuses writes and searches (vector.ErrModelMismatch) until reset empties it; the page's next scan builds it again.

The Tagger keeps every embedding it makes in a tagging.EmbeddingCache, keyed by model and text. Tagger.Prune removes what was not used for a while, after marking what the notebook's tags are built from as used.
